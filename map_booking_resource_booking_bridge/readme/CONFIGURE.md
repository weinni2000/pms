1. Install this module; the maps and their availability states move to
   **Resource Bookings > Maps**.
2. On a zone form, under **Resources**, pick the resources the zone holds. Use
   **Resource Bookings > Maps > Maps > Create Zone for Each Resource** to
   generate one zone per material resource that has no zone yet.
3. Resource Booking managers are granted the Map Booking manager rights, so
   they can edit maps, zones and availability states.
