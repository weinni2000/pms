1. Install this module; the maps and their availability states move to
   **Properties > Maps**.
2. On a zone form, under **Properties**, pick the properties the zone holds, or
   pick **Property Tags** to hold every property carrying one of them. Use
   **Properties > Maps > Maps > Create Zone for Each Property** to generate one
   zone per property that has no zone yet.
3. PMS managers are granted the Map Booking manager rights, so they can edit
   maps, zones and availability states.
